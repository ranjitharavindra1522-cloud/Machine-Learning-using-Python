# ML - Multi-Class Wine Quality Classification

## Project Overview

This project focuses on building and evaluating machine learning models to classify wine quality into multiple rating categories based on its physicochemical properties. The primary objective is to analyze key wine attributes—such as acidity, sugar levels, and alcohol content—to accurately predict quality ratings and provide actionable insights for quality control.

## Tasks Covered

The analysis covers critical machine learning workflows, including:

1. **Data Preprocessing & Cleaning**: Handling missing values, outlier detection, feature scaling, and data normalization.
2. **Exploratory Data Analysis (EDA)**: Visualizing feature distributions, correlations between chemical properties, and target class balance.
3. **Feature Engineering**: Transforming chemical attributes and selecting key predictors for model performance.
4. **Multi-Class Model Training**: Implementing algorithms such as Decision Trees, Random Forests, Support Vector Machines (SVM), and Gradient Boosting.
5. **Model Evaluation & Tuning**: Assessing models using Precision, Recall, F1-Score, and Confusion Matrices, alongside hyperparameter optimization (e.g., GridSearchCV).
6. **Insight Extraction**: Identifying top factors influencing overall wine quality.

## Technologies Used

* **Language**: Python 3.x
* **Libraries**:
  * `Pandas`: Data manipulation and tabular analysis.
  * `NumPy`: High-performance numerical computations.
  * `Matplotlib` & `Seaborn`: Data visualization and correlation heatmaps.
  * `Scikit-Learn`: Machine learning algorithms, preprocessing tools, and evaluation metrics.

## Files in the Repository

* `Wine_Quality_MultiClass_Classification.ipynb`: Comprehensive Jupyter notebook covering data cleaning, EDA, model training, evaluation, and visualizations.
* `Dataset/`: Directory containing the red and white wine quality datasets used for training and testing.
